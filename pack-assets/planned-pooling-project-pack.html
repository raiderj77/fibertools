Worksheets, three worked projects, and a dye-lot buying checklist for planned color pooling

A printable companion to the free Planned Color Pooling Calculator at FiberTools — the calculators stay free; this pack is the paper bridge from preview to finished piece.

How pooling math works here

A color repeat is the ordered whole-stitch counts of one full color sequence.

Row width = repeat + adjustment

Shift per row = row width mod repeat

Shift 0 stacks colors into columns in the sequence. Shift 1 steps the pattern one stitch per row (argyle drift); larger shifts step faster. These describe sequence offsets; the grid shows the turned fabric.

Turned rows are worked back across, so the fabric mirrors while the sequence keeps consuming in order.

Measure, preview, then swatch

Record one complete sequence, try nearby widths, and work a swatch at the planned width. Keep the trial that suits your real fabric and use its measured yarn consumption for your project plan.

Limits

Whole stitches only; color boundaries can land inside a stitch. No foundation-chain or turning-chain consumption is modeled. Tension, joins, edges, and repeat variation change real fabric. The grid is an idealized planning aid, not a guaranteed pooling outcome.

Yardage, step by step

Example swatch: 10 rows use 6.5 yards.
Yards per row = 6.5 ÷ 10 = 0.65 yards/row.
Planned rows = 220 rows × 1 panel(s) = 220 rows.
Total stitches = 21 × 220 = 4620 stitches.
Total yarn = 0.65 × 220 = 143 yards.
With 20% overage = 143 × (1 + 20/100) = 171.6 yards.
Skeins = round up (171.6 ÷ 231) = 1 skein(s) of 231 yards each.

Dye-Lot Buying Checklist

  • Buy all the yarn for the project before you start — pooling eats the sequence in order and a mid-project reorder can change the repeat.
  • Check the dye-lot number on every label matches; photograph the labels with the first swatch.
  • Buy the swatch-math yardage plus the overage (15-20 percent, or one extra skein on narrow pieces) from the SAME lot.
  • Compare each skein: unwind a few yards and confirm the color sequence and section lengths look the same before you wind it into your project.
  • Keep one full label and the receipt with the project until it is finished.
  • If a skein runs out mid-row, start the new skein at a color-section boundary, not mid-color.
  • If you are forced to change dye lots, hide the change at a seam, an edge, or a panel break — expect the repeat lengths to differ slightly.

Troubleshooting Grid

SymptomLikely causeFix
Pattern drifts diagonally but I wanted straight columnsShift per row is not 0 — the row width is not the repeatSet adjustment so row width equals the repeat exactly (shift 0).
Columns stack, then slowly creep sideways after many rowsTension changes across the row or between sessionsRe-swatch at project width; keep the measuring routine identical; note the row where creep starts in the trial log.
Pattern breaks suddenly at one point in a rowA factory join interrupted the color sequenceCut the yarn at the join and restart at the beginning of the color sequence.
New skein starts in the middle of a colorSkeins do not all start at the same sequence pointWind off or cut forward to the start of a color section before joining.
My edges eat stitches the preview does not showSetup and turning chains consume part of the repeatThe model assumes no chain consumption — measure sections in worked stitches only and treat chain stitches as outside the repeat.
One color band keeps getting wider or narrowerRepeat length varies between skeins or dye lotsMeasure the new skein sections before joining; if they differ, reserve that skein for a separate panel.
Color boundaries look fuzzy or splitA boundary lands within a stitch instead of between stitchesCount sections in whole stitches only and re-measure at a clean boundary; the grid is idealized.
Pooling worked in the swatch but not in the pieceGauge or tension at project width differs from the swatchSwatch at the full project width; adjust hook size before adjusting the stitch counts.

From preview to finished piece

  1. Measure one full color sequence in whole stitches and record your yarn and dye lot.
  2. Try widths in the free calculator, then swatch at project width and log the result.
  3. Measure swatch yardage, scale to all planned rows, add overage, and round up skeins from the same lot.
  4. Track your rows and check tension, sequence boundaries, and each new skein as you work.
