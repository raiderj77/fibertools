# FiberTools mission

`CLAUDE.md` is the current repository contract. This product summary never overrides it.

FiberTools helps knitters, crocheters, and fiber artists plan projects with free, privacy-first, deterministic calculators and references.

## Product promise

- No account or email is required for self-service calculators.
- Project inputs remain in the browser unless a page explicitly discloses a separate server workflow.
- Results are planning aids, not guaranteed outcomes.
- Formulas remain explainable, bounded, and regression tested.
- Core tools remain accessible by keyboard, screen reader, and small-screen layouts.
- Optional commercial paths never reduce access to the free calculators.

## Primary visitor jobs

1. Calculate yarn and materials.
2. Fix gauge, sizing, and stitch counts.
3. Plan a crochet or knitting project.

## Trust principles

- State limitations clearly.
- Publish only claims supported by current evidence.
- Keep user inputs and free-form text out of analytics.
- Fail closed when payment, delivery, provider, or owner-release evidence is incomplete.
- Preserve owner-controlled publication, experiment, and protected-record boundaries.
